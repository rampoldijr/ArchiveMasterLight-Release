# Support, Feedback & Voluntary Contributions

Thank you for using **ArchiveMaster Light 1.0.0**.

---

## Reporting Issues & Feedback

ArchiveMaster Light 1.0.0 is the developer's first publicly released software project. User feedback, reproducible bug reports, and usability suggestions are genuinely welcome as part of the ongoing learning and improvement process.

To report a problem or suggest an improvement, please open an issue on the official distribution repository:
https://github.com/rampoldijr/ArchiveMasterLight-Release/issues

### What to include in a bug report:
1. **Windows version:** (e.g., Windows 11 Pro 64-bit build 23H2).
2. **Application version:** `1.0.0`.
3. **Reproduction steps:** Clear, step-by-step description of what you did before the issue occurred.
4. **Observed vs. Expected behavior:** What actually happened versus what you expected.
5. **Screenshots or error messages:** Relevant logs or dialog text, with any personal filenames or paths redacted.

> **Privacy Warning:** Never share passwords, access keys, tokens, personal documents, or sensitive data in public issues.
